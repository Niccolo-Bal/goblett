Zero-knowledge voting on Arc

Public voter list.
Private ballots.

Goblett runs elections where anyone can check who was allowed to vote and that every vote was counted once, but nobody, including the organizer, can tell which wallet cast which ballot.

How it works

Four steps, one contract

01 / Create

Fix the rules

The organizer deploys an election with its candidates, voter wallets and schedule. After that nothing can be changed, by anyone.

02 / Register

Sign once

Each voter signs a message with their wallet. It adds an anonymous identity to the election and carries no vote.

03 / Vote

Prove, don't reveal

The browser builds a zero-knowledge proof that says "I am one of the registered voters" without saying which one.

04 / Count

Verify the result

The contract counts the ballots and rejects any second vote. The tally is on-chain for anyone to check.

Why Goblett

Built so nobody has to be trusted

No coordinator

There is no server that sees votes and no admin who can pause, edit or recount. The election is its contract.

No gas, no burner wallets

Voters only sign. Relayers submit the transactions and are repaid from funding the organizer attaches to the election.

Any EVM wallet

A voter's wallet can stay on Ethereum or any other network. An address is the same everywhere, and so is its signature.

Network privacy

Registrations and votes travel through an Oblivious HTTP relay, so the servers that carry a ballot don't see the voter's IP address.

Single choice or ranked

Run a first-past-the-post vote, or a ranked-choice vote with an instant runoff counted by the contract.

Open source

Contracts, relayer and this site are public. Built on Semaphore, Nostr and Arc, with nothing hidden behind an API.

Know the limits

What it does not hide

  • The running tally is public while voting is open.
  • A voter can choose to prove how they voted, so vote buying is not prevented.
  • Anonymity is only as large as the group: with three registered voters, a ballot is one of three.
  • Network privacy depends on the relay and gateway operators not sharing logs, and timing is still visible.

Read the code, then run an election

Everything Goblett does is in the repository: the contracts, the audit notes and the known limits.
